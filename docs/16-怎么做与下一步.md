## 1. 一句话

折跃门（wgp）是 **纯 P2P 打洞组网**：两端直连传业务，第三方只当信令/观察者，**不转发业务包**。

```
客户端 A ──打洞直连── 客户端 B
     \                 /
      种子节点 wgp-node（DHT + 观察者/STUN + TCP 信令兜底）
```

- **内核**（`kernel/`）：只管打出一条 `PunchedLink`，不跑应用、不建 QUIC。
- **服务端**（`server/wgp-node`）：单进程四职；`wgp-node` 静态 IP 完整版，`wgp-node-hobby` 家宽贡献版（强制拒中转）。
- **客户端**（`client/wgp-client`）：参考外围——开房 / 加入 / 打印事件，还不是产品。
- **还没做**：QUIC 数据面、端口转发（wgp-port）、虚拟网卡（wgp-tap）、界面。

硬约束（00 §1）：H1 零中继、H2 端到端加密、H4 内核只管打洞、H6 发包预算闸门。

## 3. 怎么做（按这条路走）

### 3.1 本机编译（Windows 开发机已通）

```bat
cd /d H:\mclink core
cargo test --workspace
cargo build --release
```

产物：

- `target/release/wgp-node.exe`
- `target/release/wgp-node-hobby.exe`
- `target/release/wgp-client.exe`

交叉编译 Linux 二进制（本机已有 `x86_64-unknown-linux-gnu` target 目录）：

```bat
rustup target add x86_64-unknown-linux-gnu
cargo build --release --target x86_64-unknown-linux-gnu
```

产出在 `target/x86_64-unknown-linux-gnu/release/`。链接器若缺，改到 Linux 上直接编更省事。

### 3.2 部署家庭宽带贡献节点到 Linux 服务器（当前主线）

**不要**把端口写进 unit。二进制默认就是 07 §6：UDP 11010 + UDP 3478 + TCP 3481；要改走 `/etc/wgp-node/env`。

在服务器上：

```bash
# 0) 语法自检（开发机 Git Bash 坏了，必须在 Linux 上做）
bash -n server/deploy/install-hobby.sh
systemd-analyze verify server/deploy/wgp-node-hobby.service

# 1) 构建 + 全测（首次上线必做，含 cfg(unix) ICMP）
sudo apt update && sudo apt install -y build-essential pkg-config
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
cargo test --workspace
cargo build --release

# 2) 装服务（创建 wgp 用户、拷二进制、装 unit、enable --now）
sudo bash server/deploy/install-hobby.sh

# 3) 防火墙（nft 文件首行 flush ruleset，会清空宿主机全部规则，脚本故意不代劳）
sudo apt install -y nftables
sudo nft -f server/deploy/wgp-node.nft
sudo systemctl enable --now nftables
```

通过标准：

```bash
journalctl -u wgp-node-hobby -n 30
# 必须出现：已就绪（种子+观察者+承诺兜底）| node_id=.. | DHT bind=0.0.0.0:11010 | STUN=:3478 | TCP=:3481
# 必须出现：贡献模式：拒绝 Forward 中转

sudo systemctl restart wgp-node-hobby
journalctl -u wgp-node-hobby | grep node_id
# 两次 node_id 前 4 字节必须相同（身份文件 /opt/wgp-node/node_identity.key 勿删）
```

改端口 / 限频：编辑 `/etc/wgp-node/env`（模板 `server/deploy/wgp-node.env.example`，键与 `server.rs::collect_env()` 一一对应）→ `systemctl restart wgp-node-hobby`。家宽还要把 11010/3478/3481 从光猫映射到这台机器。

完整版（允许中转）把二进制和 unit 换成 `wgp-node` / `wgp-node.service`，**同一台机只启一个**。

### 3.3 客户端联调（种子起来之后立刻做）

两台异 NAT 设备（家宽 × 手机热点最有代表性）：

```bash
# 机器 A（房主）
wgp-client 开房 --name 测试房 --key 自己设一个 \
  --seed udp://轻松.躺进.icu:11010,tcp://轻松.躺进.icu:3481

# 机器 B（把 A 打印的 U/ 码贴过来）
wgp-client join U/xxxx-xxxx-xxxx-xxxx \
  --seed udp://轻松.躺进.icu:11010,tcp://轻松.躺进.icu:3481
```

种子换成你刚部署的公网 IP/域名。`--observer` 缺省会跳过 NAT 探测、走 TCP 兜底——真打洞验证请带上观察者，例如 `--observer <种子公网IP>:3478`。

通过标准（DEPLOY §6 / 15 文档账本）：

| 项 | 通过 |
|----|------|
| 种子连通 | 1.5s 内能入表，日志有房间事件 |
| 观察者 | Binding 回显 nonce 一致 |
| UDP 打洞 | 异 NAT 下 `LinkYielded` 且 rank=Primary，高置信 ≤3.05s |
| TCP 兜底 | 一端禁 UDP 出站仍能 Degraded |
| 身份 | 客户端 `wgp-client.key`、服务端 `node_identity.key` 重启不变 |

这一步通过，阶段 3 才算完。没通过不要开阶段 4。

### 3.4 配置优先级（两端同一套）

```
命令行 --flag  >  环境变量 WGP_*  >  配置文件  >  二进制默认值
```

服务端键：`BIND` / `STUN` / `TCP` / `HOBBY` / `OBSERVER_RATE_LIMIT` / `OBSERVER_RATE_WINDOW` / `IDENTITY` / `LOG_LEVEL` / `CONFIG`。
客户端种子：`--seed` 或 `WGP_SEED`。内核零内置部署地址。

## 4. 下一步（只按这个顺序，不要并行铺摊子）

### 下一步 1 — 把 hobby 节点钉在 Linux 服务器上（本周）

1. 真机 `cargo test --workspace` 全绿。
2. `install-hobby.sh` + nft + 端口映射。
3. `node_id` 重启不变。
4. 从外网用客户端 `--seed` 打到这台机器。

交付物：一台常驻、日志干净、身份固定的贡献种子。没有这一步，后面全是空转。

### 下一步 2 — 双端打洞账本（紧接着）

按 3.3 的表跑完。失败就停在内核/NAT 侧修，不要开始写 QUIC。

建议最小复现：同一局域网先走 LAN 组播（应 <1s）；再拆到异 NAT。对照 `nat/NAT实测数据综合报告.md` 看是 NAT1/2/3（应 >95%）还是 NAT4。

### 下一步 3 — 数据面（阶段 4 的第一刀）

内核契约已经定死（14）：外围从 `PunchedLink` 取出 socket + `session_key`，自己建连接。

顺序：

1. **UDP → QUIC-TLS-PSK**（quinn + rustls，方案 a，无双重加密）。`KeyExporter::take_tls_psk` 一次性取出。
2. **TCP → TLS-PSK + 帧流**（降级档）。
3. 保活仍归内核；外围禁止自己发心跳。

这一刀的验收：两客户端 `join` 后能互发一条应用消息，而不是只看到 `LinkYielded`。

### 下一步 4 — 接入形态（二选一先做透）

00 D1 是双轨，但一次只做一条：

| 形态 | 用户感知 | 依赖 |
|------|----------|------|
| **wgp-port**（建议先做） | 把本地端口转到对端 | 下一步 3 的可靠流 |
| **wgp-tap** | 虚拟网卡 100.64/10 | 下一步 3 + `docs/12` |

wgp-port 能先让「游戏/SSH/内网服务」跑起来，比 TAP 更容易验收。
