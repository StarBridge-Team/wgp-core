| **普通节点** | DHT 路由、会话宿主 | 任意（含 NAT 后） | 全部客户端 |

## 3. 观察者协议（STUN 扩展，与 03 §3.10 互补）

**格式**：完全复用 RFC 8489 STUN 报文，Binding Request 追加三个自定义属性（0x80F0-0x80F2 未注册区；避开 0x8028 FINGERPRINT 保留值）：

```
Binding Request
 ├─ [0x0001 MAPPED-ADDRESS]（服务端回包用）
 └─ [0x80F0 WGP-PEER]    (4B PeerId | 8B Nonce | 8B Timestamp | 4B Flags)
    [0x80F1 WGP-LINK]    (2B Proto | 2B MTU | 4B RTT 预算提示)
    [0x80F2 WGP-PUNCH]   (打洞协调参数：对端 IP:Port、T_offset、窗口参数)
```

**档位语义**：标准 STUN 服务器只响应标准属性、忽略 WGP-* 扩展 → 公共 STUN 天然兼容基础档；观察者（长沙 wgp-node）读懂 WGP-PUNCH 后额外执行 §4 的交叉报告。**一套编解码，两级能力。**

**元素过程**：

```
1. 打洞双方各自向 K 个观察者（默认 2：长沙 + 一公共 STUN）发扩展 Binding
2. 观察者回包：MAPPED-ADDRESS = 它看到的请求方公网端点 + 回显 WGP-PEER/Nonce
3. 双方经 DHT 交换"我的 K 份观察报告"与对端 K 份
4. 交叉比对：
   一致 → 采用；多数一致 → 采用多数；全不一致 → 报告无观察者可用
5. 观察者自身的可信度 = 它报告的端点与公共 STUN 报告的偏差 |δ| 进质量分
```

**谎报后果分析**：谎报只能导致打洞失败或预算浪费（DoS）；探针带会话密钥派生的 HMAC（03 §3.5.5），伪造打洞包拦截于校验——不能窃取业务数据（H2）。

**限频门控（实现细节）**：观察者按**源 IP**（非 SocketAddr，防端口轮换绕过）维护令牌桶，桶满静默丢弃；周期清扫过期桶；IP 桶数上限 65536，超限整体清空重建（容量治理，防内存耗尽）。默认策略 10s 窗口 12 次/ IP，wgp-node 可配（`--observer-rate-limit/--observer-rate-window`）。

## 4. 房间键与锚点机制

```
房间键派生: room_key = SHA256("wgp/room/v1" || U/房码)   （13 文档"未来 DHT 冷启动的房间键"落实）
存储对象: { 成员表(PeerId+ed25519 签名), 锚点, epoch, 租约到期时刻, PoW 凭证 }
副本: K=3（DHT 节点集体掉线时房间不丢），锚点每 30s republish
```

**租约/继位链/epoch（防脑裂三件套）**：

```
租约   锚点每 30s 续期（写到期时刻）；成员监控，75s 无续期判掉线
继位链 成员表按 PeerId 排序 = 确定性继位顺序；候补按序尝试续期抢占
       （DHT 条件写 CAS 保证唯一成功者）；链上第一个在线者成为新锚点
epoch  每次锚点转移 +1；续期必须带 epoch；旧锚点回归发现 epoch 变 → 降级成员报到
```

新成员加入：读房间键 → 找锚点 → 报道 → 锚点通报既有成员与新成员互打（mesh 增边）。选举窗口期加入者按继位链尝试联系候补，最坏延迟 = 检测 75s + 一次 DHT 写 RTT（仅信令面，数据面零影响）。

**存储的线格式与容量治理（实现细节）**：Store RPC 载荷携带发送者的 ed25519 公钥（固定 98B 前缀 + 值），接收端强制校验 `node_id == SHA256(pubkey)` 一致才落库——伪造他人身份抢占存储计算上不可行；KV 上限 4096 条（超限逐出最旧写入，同键覆盖不计新）。节点地址簿同样身份绑定：仅经合法 Ping/Pong/Store 的可信身份入库，上限 4096 条、静默过期 30min、超限先清扫过期、再逐"最久未见"——攻击者必须持续在线才能保住席位，成本对等（代码落点：wgp-dht `node.rs` 的 `verify_identity/kv_admit/learn_addr`）。

## 5. 种子发现（多节点四层）

```
① 静态  客户端编译期内置种子列表（见 wgp-proto consts::BUILTIN_SEEDS：
         udp://轻松.躺进.icu:11010 + tcp://轻松.躺进.icu:3481，IDN 经 punycode 归一化）
② DNS   seed 域名多 A/SRV 记录（有域名即启用，改服务器不改客户端）
③ DHT   ★主机制★ 入网后邻居交换 SeedAdvertise：
         { 种子地址, 优先级, ed25519 签名 } —— 客户端学到的种子比内置更新
④ 排序  对全部候选种子做可达性探测（udp→Ping / tcp→Ping），按 RTT 排序持久化缓存
```

## 6. 服务端（种子节点）：wgp-node 部署规格

> 双形态同源（`server/wgp-node`）：`wgp-node` 静态 IP 完整版；`wgp-node-hobby`
> 家庭宽带贡献版（强制拒绝 Forward 中转，PCDN 自保）。当前线上种子为贡献服务器；
> 原长沙静态服务器暂不可用。

| 项 | 规格 |
|----|------|
| 机器 | 1C1G 公网 VPS / 家宽贡献机，无状态、无数据库、无磁盘增长 |
| 端口 | UDP 11010（DHT 信令）、TCP 3481（信令兜底，长度前缀帧）、UDP 3478（STUN/观察者） |
| 角色 | NodeRole::Seed，单进程四职（种子/观察者/STUN/承诺兜底） |
| Feature | wgp-core feature="node"（编译不含打洞引擎） |
| 日志 | 仅入网节点数/观察 QPS/异常报文（脱敏），不记任何会话内容 |

**宕机表现**：已建 mesh 业务零影响（两两直连不经它）；新加入可靠客户端路由缓存与公共 STUN 完成判定；全冷启动才受阻（等待恢复重试）。

**去中心化演进**：现在单种子全包 → 社区公网节点分担观察者/转发（种子退居兜底）→ 远期多种子互相接济。

## 8. 威胁与防御

| 威胁 | 防御 |
|------|------|
| 转发者替换公钥 | 承诺-揭示（01 §1.2.2） |
| 观察者谎报端点 | 交叉验证 + 探针 HMAC + 预算闸门（H6） |
| 日蚀攻击 | 种子多样 + ed25519 节点身份持久化 + §5 四层发现 |
| 地址簿/KV 毒化（伪造身份占位） | 身份绑定（node_id = SHA256(pubkey) 硬校验）+ 容量治理（上限/过期/最旧淘汰） |
| 观察者洪泛（端口轮换绕过） | IP 键控限频 + 周期清扫 + 桶上限清空 |
| 刷房间注册 | PoW 凭证（集成于存储对象） |
| 信令重放 | Seq 去重 + 60s 窗口 |
| 旧锚点诈尸 | epoch 校验 |

**结论**：第三方全部降级为"不可信即可用"；所有攻击收敛为 DoS；机密性与完整性由 H2 独立保证。
