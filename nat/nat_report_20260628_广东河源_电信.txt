【六、检测方法说明】
  Test I    : 普通 Binding Request,获取映射地址
  Test II   : 带 CHANGE-REQUEST(change-port) 标志,探测是否能从不同端口接收响应
  Test III  : 带 CHANGE-REQUEST(change-ip + change-port),探测是否能从不同 IP 接收响应
  同端口测试: 复用同一本地 socket 连续探测,观察 NAT 分配的端口是否变化
              若端口稳定 -> 不是 Symmetric;端口抖动 -> 高度疑似 Symmetric
  IPv6 测试 : 通过 connect 到公网 v6 端点推断本机出口 v6,再用 IPv6 STUN 获取公网 v6
  分类规则 (单服务器简化版) :
    - Test I 失败                       -> UDP Blocked
    - 映射稳定 + Test II/III 成功       -> Open Internet
    - 映射稳定 + Test II 成功           -> Full Cone NAT
    - 映射稳定 + Test II 失败           -> Port Restricted Cone NAT
    - 映射变化 或 同端口测试端口抖动    -> Symmetric NAT
