## 1. 设计哲学

**"无中继 ≠ 无第三方"**——打洞在数学上需要"观察者"报告双方公网端点，承诺-揭示需要"转发者"。折跃门的做法是让这些第三方**不可信也能安全运行**（H1/H2 保证），从而去掉"中继业务流量"这个最贵的基础设施。

## 2. 硬约束（不变式）

| 编号 | 约束 |
|---|---|
| H1 | 纯 P2P 零中继：业务数据端到端直连，任何第三方不得转发业务流量 |
| H2 | 端到端加密：X25519 ECDH（承诺-揭示）产会话密钥；数据面 QUIC-TLS/TLS-PSK；逃生通道 AES-GCM 帧 |
| H3 | 零自建成本：信令去中心化，唯一现有基础设施 = 公网种子 + 公共 STUN 兜底 |
| H4 | 内核只管打洞：不解析应用协议、不做转发重传、不做应用适配 |
| H5 | Rust；禁止读取系统时间（仅 Instant + 网络锚点） |
| H6 | 发包自限：≤47 包/轮、≤500 包/10 分钟，调度器是唯一发包点 |


## 5. 内核设计（wgp-core）

**契约**：内核职责终点 = 产出一条已打通的链路（`PunchedLink`）；保活由内核唯一负责，外围零心跳；调度器是唯一发包点。

**内核主状态机**（每 Peer 一会话实例；调度器按房间维度共享预算）：

```
Idle → Preprobe → RoomLookup → Negotiating → Punching → Connected
Punching:  LAN 发现 ∥ UDP 三波 ∥ TCP simultaneous open（T1–T4 触发）
Connected: 保活循环 / 降级档 30s 探测升级 / NAT 重绑定重打洞
全灭 → ICMP 逃生 → 死局判定（04 D5 评分 ≥70）→ 明确告知用户
```

**TCP 兜底触发（T1–T4，任一满足）**：T1 预判 UDP 不可达；T2 UDP 三波全灭；T3 UDP 通但 QUIC 握手超时 3s（疑 DPI）；T4 运营商画像差 + 对端同意。

**对外接口**（14 文档定版）：`PunchedLink`、`LinkSink`、`KeyExporter`、`SignalingBus`、`LinkControl`、`RoomApi`、`ProbeCarrier`、`KeyAgreement`。三条路径：`Engine::new_link`（client）、`Engine::join_room`（client）、`Engine::run_node`（node）。

**生命周期六条款**：① yield 一次语义；② 旧链路宽限 30s；③ 密钥单次转移（zeroize 审计点）；④ 保活唯一权（suspend_keepalive 受否决权）；⑤ 重连幂等（新旧 session_key 必然不同）；⑥ 取消语义（JoinHandle 取消后 100ms 清理）。

## 6. 信令面：去中心化 DHT（07 文档）

| 角色 | 职责 | 公网要求 |
|---|---|---|
| 种子 | bootstrap 冷启动入口 | 必须 |
| 观察者 | 报告节点公网端点（STUN 语义） | 必须 |
| 转发者 | 转发承诺/揭示、打洞参数 | 任意（所有 DHT 节点，不可信即可用） |
| 锚点 | 房间在线协调者（成员表、通报互打） | 任意 |
| 房主 | 房间创建者，权限角色 | 任意 |

- **种子 = wgp-node 单进程四职**：DHT 种子 / 观察者 / STUN 响应器（3478）/ 承诺转发兜底。无状态、不碰业务包。
- **观察者协议复用 STUN 报文扩展**：Binding Request 附 0x80F0 WGP-PEER / 0x80F1 WGP-LINK / 0x80F2 WGP-PUNCH——标准 STUN 服务器天然忽略扩展，**一套编解码，两级能力**。
- **多节点发现四层**：① 配置注入种子端点 → ② DNS 多 A/SRV → ③ DHT 内 SeedAdvertise 交换（主机制）→ ④ 可达性排序 + 本地缓存。
- **多人房间**：U/ 码 = DHT 房间键（`room_key = SHA256("wgp/room/v1" ‖ 房码)`）；房主与锚点分离；锚点租约 30s 续期 / 75s 超时；继位链按 PeerId 序 + DHT CAS 抢占；epoch 防诈尸。
- **威胁模型**：第三方降级为"不可信即可用"；攻击面收敛为 DoS；数据机密完整性由 H2 独立保证。

## 7. 数据面与传输

| 路径 | 载体 | 加密 | 说明 |
|---|---|---|---|
| 主路径 | UDP 打洞 → 同 socket 双向 QUIC | TLS-PSK 注入会话密钥（无双重加密） | 0-RTT 快连、连接迁移吸收 NAT 重绑定 |
| 兜底 | TCP simultaneous-open | TLS-PSK + wgp 帧流 | T1–T4 触发，rank=Degraded |
| 逃生 | ICMP identifier 打洞 | AES-256-GCM 帧（会话密钥 HKDF 派生） | 仅信令级流量，Win iphlpapi / Unix ping-socket 双后端 |
| LAN | 组播 beacon 发现 | lan_auth HMAC | 同网段跳过打洞，<1s 直连 |

TransportProfile 三档：reliable stream / unreliable datagram / hybrid。密钥轮换移交 QUIC Key Update / TLS KeyUpdate，内核只交付初始会话密钥。

## 8. 安全模型（01 文档）

**承诺-揭示（Commit-then-Reveal）**：双方先互换 `commit = SHA256(pubkey ‖ nonce)`，后揭示 `pubkey + nonce`。不可信转发者想替换公钥必须找到 SHA-256 第二原像——计算上不可行。揭示验证失败 → 立即断连 + 24h 黑名单；commit 3s 超时**不降级**。

**HKDF 派生**：`salt = SHA256("zheyuemen/v1/ecdh-salt")`；`info` 绑定双方公钥+nonce+时间锚点；一次展开产出会话密钥、方向隔离 nonce 前缀、PSK identity、punch_key、hb_key（代码落点见 11 号文档）。

**威胁与防御**：转发者替换公钥→承诺-揭示；观察者谎报端点→交叉验证+探针 HMAC+预算闸门；日蚀→种子多样+ed25519 身份持久化；地址簿/KV 毒化→身份绑定（node_id=SHA256(pubkey) 硬校验）+容量治理（4096 上限/30min 过期）；观察者洪泛→IP 键控限频（12 次/10s）+桶上限清空；刷房间注册→PoW；信令重放→Seq 去重+60s 窗口；旧锚点诈尸→epoch 校验。

## 9. 全链路流程（15 文档）

```
Phase 0 常驻预探测：时间锚点(NTP/HTTP) + NAT 判定(双观察者) + 出站预判 + 模型缓存（5 分钟）
Phase 1 建房：U/ 码派生 → DHT 写房间键 → 30s 租约循环 → LAN beacon
Phase 2 加入：DHT 查键 → 找锚点 → 报道 → 成员表更新
Phase 3 承诺-揭示（约 3 RTT，经任意 DHT 转发者）：commit → reveal → shared → HKDF → 能力位交换
Phase 4 观察与测量（并行，约 600ms）：K=2 观察者报告 → DHT 交换 → 交叉比对 → 步长学习 → 时间对齐
Phase 5 竞速打洞：LAN ∥ UDP 三波(21+15+11, 800ms/波) ∥ TCP simultaneous-open（预算 ≤47/轮）
Phase 6 验证与握手：punch_key HMAC 过 → yield PunchedLink → QUIC/TLS-PSK → Connected
Phase 7 稳态保活：动态心跳 500ms–15s + NAT 超时学习 + 降级档 30s 升级 + 端口监控
Phase 8 清理：成员表除名、停租约、密钥全 zeroize、socket/预算归还
```

资源账本：LAN 命中 <1s ≈0 包；UDP 高置信 ~650ms ≤21 探针；UDP 全灭→TCP 3–6s ≤47 包；ICMP 逃生 +2–4s；死局判定 10–15s 必出报告。**Phase 6 打通后，内核与第三方在业务存续期零交互。**

## 10. 关键算法要点（代码落点在 10–14 号文档）

| 算法 | 要点 |
|---|---|
| 步长学习 | 3 次 STUN 学步长模式 → 信令互通 → 集中探测预测窗口；置信度 = 1/(1+方差/100) |
| 三波探测 | 21 包精准窗口(±50) → 15 包回退 → 11–36 包撒网(±3000)；边发边收，150ms 时序压缩窗 |
| 时间协调 | 禁 SystemTime；Tier1 网络锚点(NTP/HTTP) + Tier2 RTT 相对测量 + Tier3 Peer 互助；信令只传 T_offset 相对偏移 |
| 双模定时器 | Precision(忙等, <1ms) / Normal(sleep)；高精度连续失败自动无感切换 |
| 预算闸门 | 单侧 ≤47 探针/轮；会话 ≤500 包/10min；调度器唯一发包点 |
| 保活 | 动态间隔 500ms–15s，滑动窗口 20 次成功率驱动；NAT 超时在线学习（25s 保守→120s 上限） |
| 死局识别 | 对称NAT 30 + CGNAT 25 + 有状态墙 20 + TTL>3 10 + UDP 封禁 15，≥70 阻断并给出诊断报告 |
