|---|---|---|---|---|---|
| `wgp-proto` | kernel/wgp-proto | 协议层：包格式/常量/编解码 + STUN 最小子集 + U/ 房间码派生（纯数据，**零依赖**） | 无 | — | 库 |
| `wgp-crypto` | kernel/wgp-crypto | 密码层：承诺-揭示、HKDF、探针 HMAC、逃生 AEAD、KeyAgreement（PQ 可插拔） | x25519-dalek, rand_core, sha2, hkdf, hmac, aes-gcm, zeroize | — | 库 |

| `wgp-core` | kernel/wgp-core | 内核门面：Engine + PunchedLink 交付物 + 全部对外 API | wgp-proto, wgp-dht, tokio, socket2（+client 时 wgp-punch/wgp-crypto/rand_core/sha2） | `client`(默认) / `node` | 库 |

| `wgp-client` | client/wgp-client | 客户端 CLI：开房/加入/事件打印（参考外围） | wgp-core(client), wgp-dht, wgp-proto, rand_core, tokio | 默认 client | **1 个 bin** |

**feature 裁剪（00 ADR D1 的编译期落点）**：

```toml
# kernel/wgp-core/Cargo.toml
[features]
default = ["client"]
client = ["dep:wgp-punch", "dep:wgp-crypto", "dep:rand_core", "dep:sha2"]
node = []
```

- `client`（默认）：打洞/信令/载体/密钥导出全量——engine 五子模块、orchestrator、exporter、link、servers、transport、types 全部编译。
- `node`：**空 feature**，裁剪由 `#[cfg(feature = "client")]` 反向实现——服务端构建（`default-features = false, features = ["node"]`）时自动收敛，编译产物**不含打洞引擎与密钥协商逻辑**。

## 3. 依赖关系图

```
                 ┌────────────┐
                 │ wgp-proto  │  （零依赖，纯数据）
                 └─────┬──────┘
           ┌───────────┼──────────────┐
           ▼           ▼              ▼
     ┌──────────┐ ┌──────────┐  ┌──────────┐
     │wgp-crypto│ │wgp-punch │  │ wgp-dht  │
     └────┬─────┘ └────┬─────┘  └────┬─────┘
          └─────┬──────┴──────┬──────┘
                ▼             ▼
           ┌─────────────────────┐
           │      wgp-core       │  feature: client(默认)/node
           └──────────┬──────────┘
              ┌───────┴────────┐
              ▼                ▼
        ┌──────────┐     ┌────────────┐
        │wgp-node  │     │ wgp-client │
        │(node面)  │     │(client面)  │
        └──────────┘     └────────────┘
```

依赖纪律（00 §3）：单向 `proto ← crypto ← punch ← dht ← core`；`proto/crypto` 禁止依赖 tokio；调度器是唯一发包点；密钥只在 `Engine` 与 `PunchedLink` 间流转。
