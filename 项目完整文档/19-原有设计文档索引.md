## 2. 逐篇摘要

### 00-架构总览.md（架构锚点，先读 §1 硬约束、§11 阶段）

全项目架构锚点：六条硬约束（H1 零中继 / H2 端到端加密 / H3 零自建成本 / H4 内核只管打洞 / H5 禁读系统时间 / H6 发包预算）；12 条 ADR（D1 双轨接入、D2 去中心化 DHT、D3 QUIC 统一数据面、D4 状态机+竞速、D6 PQ 可选、D7 房间 mesh、D8 扩散穿透 V2、D9 ProbeCarrier 抽象、D10 TCP 兜底竞速、D11 逃生与 LAN、D12 运维规格）；crate 清单与依赖纪律；内核设计契约与状态机；信令面职能重分配；数据面；未来线预留；第三方依赖分级许可（L1 硬许可/L2 外围/禁止清单）；胜算评估；文档体系映射；四阶段开发划分。

### 01-安全与加密算法.md

E2EE 架构：威胁模型说明（诚实转发下服务器无法解密；恶意服务器可 MITM → 承诺-揭示缓解）；X25519 选型；**承诺-揭示流程 22 步**（commit=SHA256(Pub‖nonce)，3s 超时不降级，揭示失败=断连+24h 黑名单，承诺碰撞重试最多 1 次）；HKDF 细节（盐 `zheyuemen/v1/ecdh-salt`、info 绑定公钥+nonce+ServerTime、48B 输出 = 32B 密钥 + 2×8B 方向 nonce 前缀）；AES-256-GCM 帧格式（**仅 ICMP 逃生通道**）与 Nonce 管理（方向派生前缀 + Counter + 1024 位重放位图）；密钥轮换（>50GB / 接近 u32::MAX / >24h / 安全告警四触发，30s 双密钥窗口，全生命周期 zeroize 清单，≤1 次/分钟防洪泛）；为何不用邀请码 PAKE（8 位 Base36 熵仅 41bit，恶意服务器可离线爆破）。

### 02-应用适配与优化算法.md

通用应用优化（对齐维度 F）：AppType 传输策略矩阵（8 类历史参考，压缩为三档 TransportProfile：reliable stream / unreliable datagram / hybrid）；TCP_NODELAY 强制开启（对抗 Nagle+Delayed ACK ~400ms 停顿）；应用层心跳与 P2P 保活合并算法（对齐窗口 T_heart/4，复合心跳包格式）；小包极速透传与零拷贝（内存池三档 64/128B 对齐，目标 80% 小包零拷贝、CPU <1μs）；MTU 自适应与防分片（Pre-connect + Runtime PMTUD，DF 探测逐级递减，应用层预分片 ≤64 片）；GameUdp 场景 UDP 原生直通（RakNet GUID 映射，LRU 30s）。

### 03-核心打洞与穿透算法.md（引擎主体，最长的一篇）

§3.2 纯 TCP 信令低延迟（TFO、定长二进制 ≤64B、连接预热、零分配解析、全双工）；§3.3 时间戳协调（**禁 SystemTime**，三层时间源：Tier1 网络锚点 NTP/淘宝 HTTP/信令 Date 头、Tier2 RTT 相对测量、Tier3 Peer 互助；信令只传 T_offset 相对偏移；精度四档分级降级 ±1ms→放弃精确协调；DualModeTimer 双模定时器含完整 Rust 参考实现）；§3.4 运营商差异化端口预测（步长学习 PortStepModel 参考实现、信令互通、七样本实测表、四类步长特征自适应策略）；§3.5 三波探测（21+15+11 参数表、时序图、探测包 31B 格式含 12B HMAC AuthTag）；§3.6 对称 NAT 与防火墙协同（识别、四策略 A–D）；§3.7 心跳动态频率保活（HeartbeatController 参考实现、心跳携带步长校准 19B/23B 格式）；§3.8 NAT 映射超时自适应学习（Conserv→Probing→Stable→Recovering 状态机，带宽节省 79%/58%）；§3.9 后台预探测零等待连接（5 任务清单、缓存失效表、网络切换处理）；§3.10 防火墙类型识别（无状态/有状态/DPI 三阶段探测）；§3.11 无状态防火墙三次握手变种（TCP 封装打洞 / UDP 伪装 TCP）。

### 03-2-大内网极致穿透预案.md（V2）

问题定义（三层 NAT 拓扑，传统盲猜 0.0125%）；**扩散穿透**核心思想（不一次穿透三层，一层层击穿，每层结果缩小下一层范围）；扩散包格式（Magic 0x5747 / Depth / Layer / PeerID / PrevPort / Nonce / TS）；LayerProbe 层数探测（TTL 逐跳，回复 IP 私网/CGNAT/公网判定，最大 4 层，4–20s 不计入 1.5s 打洞预算，作后台预探测）；三层包数分配 15+15+11=41 包；每层独立步长学习；与标准三波的回退融合（单轮永不超 47 ）；未解决问题表；分五阶段落地；竞品多层大内网直连成功率对比（节点小宝/星空组网/好朋友/蒲公英/EasyTier 5–15%/ZeroTier/Tailscale 均 <5% 靠中继，折跃门扩散 ≈10–20% 零中继）；共享端口池推断。

### 04-边缘辅助与容错算法.md

六项边缘算法：§4.2 高延迟补偿 DWC（Δ_signal=max(RTT)×1.5+100ms、W_punch=RTT×2+3σ+200ms、脉冲式发包 40ms×2 包）；§4.3 跨运营商协议切换（ProtocolSelector 参考实现、四运营商 QoS 画像、切换流程与 ≤1 次/30s 限频）；§4.4 实时端口监控（PortStable/Shifted/NetworkChanged/NatTypeChanged 四消息与打洞线程协作协议）；§4.5 自适应退避（Exponential/LinearWithJitter/Fixed 三策略、放弃决策树 3→15 次）；§4.6 死局识别 D5（评分模型：对称 30+CGNAT 25+有状态墙 20+TTL>3 10+UDP 封禁 15 ≥70 阻断；TTL 判层；CGNAT 100.64/10 检测；用户体验文案与诊断日志格式；65–75 边界警告不阻断）；§4.7 资源受限设备轻量化（内存/CPU/能耗优化、桌面/移动双档资源目标）。

### 07-信令面与观察者协议.md

### 12-虚拟网卡设计.md（V2 独立模块，不进入内核）

### 13-房间码派生协议.md

从（房间名称, 房间密钥）确定性派生 16 字符房间码：算法规范（index=37/ifindex=14 起，raw=name+str(index)+key，MD5 128bit → base36 → 去末尾 0 截 14 位 → I/O→1/0 消歧 → 未命中降级 ifindex → 兜底 "A"×14；输出 4 字符分组 + "U/" 前缀 + 2 位命中进制）；绝大多数输入首轮 base=36 命中；4 组标准测试向量（示例房间/123456 → U/C2G9-GYET-311W-R636 等）；校验流程（重跑比对，U/ 码非鉴权凭证）；安全边界（MD5 仅标识派生、房间密钥不参与密钥材料派生）；实现绑定（`wgp-proto::room_code::derive_room_code` 唯一权威，Python 参考实现对拍）。

### 15-全链路流程.md
