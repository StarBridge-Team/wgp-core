## 1. 部署形态总览

同一份代码、同一份配置，两个可执行形态：

| 形态 | 二进制 | 适用 | 中转能力 |
|---|---|---|---|
| **静态 IP 完整版** | `wgp-node` | 自有固定公网 IP 的服务器 | 启用全部职责（种子+观察者+STUN+承诺转发，允许 Forward） |
| **家庭宽带贡献版** | `wgp-node-hobby` | 社区贡献者家宽机器 | **强制拒绝 Forward 中转**（PCDN 自保），只承担种子+观察者+STUN+KV |

当前线上种子为贡献服务器：`udp://轻松.躺进.icu:11010` + `tcp://轻松.躺进.icu:3481`（IP 保密，只进客户端种子列表，不进文档/公告）。

**端口规划（07 §6 规格，二进制默认值）**：

| 端口 | 协议 | 用途 |
|---|---|---|
| 11010 | UDP | DHT 信令 |
| 3478 | UDP | STUN / 观察者 |
| 3481 | TCP | 信令兜底（UDP 被封时客户端由此接入，长度前缀帧） |

## 2. 配置文件与优先级

**优先级（四源合并，与 `server.rs::resolve_opts()` 同一套解析）**：

```
命令行 --flag  >  WGP_* 环境变量  >  wgp-node.conf（工作目录）  >  二进制内置默认值
```

**配置键全表**（`wgp-node.conf` 键名大小写不敏感，`-` 与 `_` 等价；环境变量加 `WGP_` 前缀）：

| 键 | 默认 | 说明 |
|---|---|---|
| `bind` / `WGP_BIND` | `0.0.0.0:11010` | DHT 信令 UDP 绑定地址（SocketAddr） |
| `stun` / `WGP_STUN` | `3478` | 观察者/STUN 端口，`none` 关闭 |
| `tcp` / `WGP_TCP` | `3481` | TCP 信令兜底端口，`none` 关闭 |
| `hobby` / `WGP_HOBBY` | `false`（贡献版恒 true） | 贡献模式：拒绝 Forward 中转 |
| `observer_rate_limit` / `WGP_OBSERVER_RATE_LIMIT` | `12` | 观察者每 IP 每窗口响应上限 |
| `observer_rate_window` / `WGP_OBSERVER_RATE_WINDOW` | `10` | 限频窗口（秒） |
| `identity` / `WGP_IDENTITY` | `node_identity.key`（工作目录） | 节点身份文件路径 |
| `log_level` / `WGP_LOG_LEVEL` | `info` | error/warn/info/debug |
| `config` / `WGP_CONFIG` | — | 显式指定配置文件路径 |

> 注意：旧纯位置参数（`wgp-node 0.0.0.0:11010 3478 3481`）仅首位 bind 向后兼容，stun/tcp 位置值已不生效（取默认 3478/3481）。

## 3. Linux 部署（systemd，当前主线）

### 3.1 首次登录顺序（DEPLOY.md §0，重要）

1. **[验证] Linux 编译与测试**——必须在动任何生产配置前完成。开发机为 Windows，`cfg(unix)` 分支（ICMP ping-socket）仅做过交叉编译验证，**未在真机跑过测试**。

3. **IP 保密**：服务器 IP 不进 README/文档/公告/群消息。

### 3.2 构建与测试

```bash
sudo apt update && sudo apt install -y build-essential pkg-config
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source ~/.cargo/env
cargo test --workspace          # [验证] 全绿；含 cfg(unix) ICMP 分支
cargo build --release           # 产出 wgp-node 与 wgp-node-hobby 两个可执行
```

### 3.3 防火墙（nftables）

```bash
sudo apt install -y nftables
sudo nft -f server/deploy/wgp-node.nft   # [验证] nft list ruleset 显示 wgp 表
sudo systemctl enable --now nftables
```

`wgp-node.nft` 规则要点（源码逐行）：

```nft
flush ruleset                                    # 首行清空宿主机全部规则——脚本故意不代劳
table inet wgp {
    set protected_udp { type inet_service; elements = { 11010, 3478 } }
    set protected_tcp { type inet_service; elements = { 3481 } }
    chain input {
        type filter hook input priority filter; policy drop;
        iif "lo" accept
        ct state established,related accept
        ip protocol icmp drop                    # ICMP 全静默（减扫描发现面）
        ip6 nexthdr icmpv6 drop
        # 业务 UDP：单 IP 限速 40 包/10s（burst 20），超限 drop
        udp dport @protected_udp ct state new counter hashlimit \
            name wgp-udp above 40/10sec burst 20 packets drop
        udp dport @protected_udp accept
        # 信令 TCP：单 IP 新建限速 20/秒
        tcp dport @protected_tcp ct state new counter limit rate over 20/second drop
        tcp dport @protected_tcp accept
        counter drop                              # 其余全拒
    }
}
```

设计原则（注释原文）：协议本身是小包低频，正常流量远低于限速，**超频即视为滥用**。

### 3.4 服务安装（两种形态二选一，同一台机只启一个）

**静态 IP 完整版**：

```bash
sudo mkdir -p /opt/wgp-node
sudo cp target/release/wgp-node /opt/wgp-node/
sudo useradd -r -s /usr/sbin/nologin wgp 2>/dev/null || true
sudo cp server/deploy/wgp-node.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now wgp-node
```

**家庭宽带贡献版**（一键脚本）：

```bash
sudo bash server/deploy/install-hobby.sh    # 建用户+装二进制+装单元+enable --now
```

### 3.5 systemd 单元要点

| 项 | 值（两个单元一致） |
|---|---|
| WorkingDirectory | `/opt/wgp-node`（存放 node_identity.key） |
| ExecStart | 完整版：`/opt/wgp-node/wgp-node --bind 0.0.0.0:11010 --stun 3478 --tcp 3481`；贡献版：`/opt/wgp-node/wgp-node-hobby`（无参数，默认即规格） |
| EnvironmentFile | 贡献版：`-/etc/wgp-node/env`（前缀 `-` = 文件可不存在） |
| User/Group | `wgp`（无登录 shell） |
| Restart | `on-failure`，RestartSec=5 |
| MemoryMax | 256M（无状态服务，限一下防异常） |
| 加固 | NoNewPrivileges=true, ProtectSystem=full, ProtectHome=true |

### 3.6 install-hobby.sh 详解

```bash
# 可调安装位置（均有默认）：
WGP_INSTALL_DIR=/opt/wgp-node   # 安装目录
WGP_RUN_USER=wgp                # 运行用户
WGP_ENV_FILE=/etc/wgp-node/env  # 环境文件
WGP_BIN=.../target/release/wgp-node-hobby   # 二进制来源
```

脚本行为（`set -euo pipefail`）：① 校验 root 与二进制/单元/模板存在；② 创建系统用户；③ `install -m 0755` 装二进制；④ **环境文件已存在则绝不覆盖**（运维调过的配置是生产资产），仅首次从模板创建（`install -m 0640 -o root -g wgp`）；⑤ 装单元 + `enable --now` + 打印 status 前 12 行；⑥ 收尾提示防火墙/改参/看日志/自检命令。

## 4. Windows 一键部署包（hobby-windows/，免编译备用）

| 文件 | 说明 |
|---|---|
| `wgp-node-hobby.exe` | 贡献版二进制（release；内部恒定 hobby，`--no-hobby` 无效） |
| `wgp-node.conf` | 配置文件（启动自动加载；键与 `resolve_opts()` 对应） |
| `start-hobby.bat` | 启动脚本（`chcp 65001`、cd 到脚本目录、透传 `%*` 参数、退出打印码） |
| `firewall-hobby.bat` | 防火墙放行（**右键管理员运行**；端口从 conf 解析，与后端同源） |

**部署步骤**：① 管理员运行 `firewall-hobby.bat`（解析 conf 得 bind/stun/tcp 端口，`none` 则不放行；netsh 写入三条固定名规则 `wgp-node DHT (UDP)`/`STUN (UDP)`/`Signal (TCP)`，conf 改端口后重跑即原位更新）；② 光猫/路由器端口映射（UDP 11010/3478、TCP 3481 映射到本机内网 IP；桥接时只在路由器映射，光猫路由模式两层都映射）；③ 双击 `start-hobby.bat`，日志出现 `已就绪（种子+观察者+承诺兜底）` 即成功；④ 可选开机自启（`shell:startup` 放快捷方式）。

**验证**：日志出现 `node_id=xx:xx:xx:xx` 与三端口；外网用手机流量 `wgp-client --seed udp://你的公网IP:11010` 能 Ping 通即入网成功。

**卸载**：删目录 + 删防火墙规则（控制面板 → 高级设置 → 入站规则搜 "wgp-node"）。

> 每次重新 `cargo build --release` 后，把新的 `wgp-node-hobby.exe` 拷入本目录，保持包内二进制与源码一致。

## 5. 运维要点

- **升级** = `cargo build --release && cp` 覆盖二进制 + `systemctl restart`（无状态，无数据迁移）。
- **身份文件即服务器全部状态**：备份 `node_identity.key`；丢失 = 节点身份重生成（被已入网路由表视为新节点，无害但不优雅）。systemd 单元靠 `User=wgp` + 工作目录权限保证仅本服务可读。
- **改端口/限频**：编辑 `/etc/wgp-node/env`（去注释）→ `systemctl restart wgp-node-hobby`；不要写死在 unit 里。
- **被打（DDoS）预案**：架构级冗余兜底（社区种子顶替 / 公共 STUN 顶替观察者）；已建立 mesh 的业务流零影响——不需要为此买高防。
- **软件内置防护**（贡献模式三件事）：拒绝 Forward 中转（唯一可能产生持续流量的路径）；观察者限频 12 次/10s/IP；身份持久化。正常流量量级：一天信令总量低于几 MB；被运营商警告先查 hobby 没开。
- **家宽无固定公网 IPv4**：IP 变化后需更新客户端 `--seed`（DDNS 域名可缓解）；有公网 IPv6 时客户端可直连（防火墙规则放行 any profile）。

## 6. 真机验证清单（DEPLOY.md §6）

| 项 | 操作 | 通过标准 |
|---|---|---|
| 种子连通 | 客户端 attach 本种子 → ping | 1.5s 内 Pong |
| 观察者报告 | 客户端带 WGP-PEER 扩展探测 | 回显 nonce 一致 + XOR-MAPPED 正确 |
| 双端打洞 | 两端各掛异 NAT（电信家宽 × 移动热点）跑 new_link | UDP 高置信 ≤3.05s |
| TCP 兜底 | 一端屏蔽 UDP 出站（T1） | TCP 交付（Degraded） |
| LAN 组播 | 同一局域网两客户端 | <1s 组播发现直连 |
| ICMP 逃生 | 两端仅放 ICMP（防火墙模拟） | EscapePayload 往返（Linux ping-socket 后端首测） |

服务端自检：`journalctl -u wgp-node-hobby -n 30` 必须出现 `已就绪（种子+观察者+承诺兜底）| node_id=.. | DHT bind=0.0.0.0:11010 | STUN=:3478 | TCP=:3481` 与 `贡献模式：拒绝 Forward 中转`；重启后 `journalctl ... | grep node_id` 两次前 4 字节必须相同。
